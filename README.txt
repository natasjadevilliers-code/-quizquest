QUIZQUEST FOR IPHONE

This folder is ready to be hosted as a small website/PWA.

Once the site has a normal https:// web address:
1. Open the site in Safari on the iPhone.
2. Tap the Safari More/Share control.
3. Tap Add to Home Screen.
4. Leave Open as Web App enabled (if shown), then tap Add.

QuizQuest will then appear on the Home Screen and open like an app.

FILES
- index.html — the quiz
- manifest.webmanifest — app metadata
- sw.js — offline cache

The app can work offline after it has been loaded from the hosted site.
